# Angular Infinite Photo Stream

Photo library built with Angular, Angular Material, and SCSS.

- **Photos** (`/`) — infinite photostream (fake API + Picsum images)
- **Favorites** (`/favorites`) — saved photos in `localStorage`
- **Photo detail** (`/photos/:id`) — full-size view and remove from favorites

## Requirements

- Node.js 24+
- npm

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Tests

```bash
npm test
```
